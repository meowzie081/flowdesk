# FlowDesk для Windows 11

Десктопный клиент использует опубликованный сайт FlowDesk. Аккаунт, отделы, «Мой день», канбан, чат и файлы общие с браузером и Telegram Mini App. Для работы нужен интернет. Node.js, Docker и локальный Supabase на компьютере пользователя не нужны.

## Выбор установщика

- `win-x64.exe` — для компьютеров с процессором Intel или AMD.
- `win-arm64.exe` — для Windows 11 на ARM. Доступен отдельный установщик ARM64; его можно также собрать через GitHub Actions.

Архитектуру можно посмотреть в «Параметры → Система → О системе → Тип системы».

## Установка и вход

1. Скачайте подходящий файл `FlowDesk-Setup-0.2.0-win-…exe`.
2. Запустите установщик. Он предлагает русский и английский интерфейс, выбор папки установки и ярлык FlowDesk.
3. Запустите FlowDesk из меню «Пуск» или ярлыка на рабочем столе.
4. Войдите по существующему логину/email и паролю FlowDesk. Если аккаунта нет, попросите владельца отдела создать его.

По умолчанию установка выполняется для текущего пользователя. Ключи Supabase и токен Telegram в приложение вводить не требуется. Google OAuth доступен в обычном браузере, парольный вход — внутри десктопного клиента.

## Управление

- `Ctrl+R` — перезагрузка страницы или переподключение при отсутствии интернета.
- `Ctrl+Shift+H` — выбор отдела.
- Меню «Вид» — масштаб и полноэкранный режим.
- Меню «Файл → Открыть сайт в браузере» — переход к веб-версии.

Размер окна и положение сохраняются. Сессия клиента отдельная от браузерной. Переустановка не обновляет серверную часть: новые веб-функции сначала нужно опубликовать на Vercel.

## Удаление

Сначала выйдите из аккаунта через меню пользователя FlowDesk. Затем откройте «Параметры → Приложения → Установленные приложения → FlowDesk → Удалить». Автоматическое удаление сохранённого профиля Electron не включено, чтобы переустановка не стирала сессию и настройки неожиданно.

## Подпись и ограничения проверки

Подготовленный установщик не подписан сертификатом издателя. Windows может показать предупреждение о неизвестном издателе. Для публичного распространения настройте Authenticode-подпись; отключать Defender или защиту Windows целиком не требуется.

Установщик собирается средствами electron-builder/NSIS. Проверяется наличие приложения и ресурсов, архитектура PE-файла и содержимое пакета. Установка и полноценная работа на настоящей Windows 11 в этой среде не проверялись. Проверки общей логики клиента и Electron на Linux описаны в [DESKTOP.md](DESKTOP.md).

Полного офлайн-режима, системных push-уведомлений и автоматического обновления установленного клиента пока нет. Внешние HTTPS-ссылки открываются в системном браузере.

## Самостоятельная сборка на Windows

Для сборки из исходников установите Node.js 22 или новее. В PowerShell из корня проекта:

```powershell
cd desktop
npm ci
npm test
npm run dist:win:x64
```

Для ARM64 используйте `npm run dist:win:arm64`. Готовый установщик появится в `desktop/dist/`. `app-config.json` задаёт HTTPS-адрес сайта до сборки.

В GitHub также можно запустить Actions → Desktop installers → Run workflow и скачать подходящий Windows artifact после успешных проверок. Автоматической публикации в Microsoft Store нет.

## Сборка в Linux/macOS без Wine

В поставке с закреплённым electron-builder 26.15.3 есть отдельный адаптер:

```bash
cd desktop
npm ci
npm run dist:win:cross -- --x64
npm run dist:win:cross -- --arm64
```

Он использует встроенный NSIS UninstallerReader для извлечения деинсталлятора, не запуская промежуточный Windows executable. Сборки этого режима не подписываются. При смене версии electron-builder адаптер требует отдельной проверки и останавливается. Обычные сборки на Windows и GitHub Actions продолжают использовать штатный путь сборщика.

Если приложение уже упаковано в `desktop/dist/win-unpacked` или `win-arm64-unpacked`, повторно собрать только установщик можно командой `npm run dist:win:cross -- --x64 --prepackaged` (или `--arm64`). Этот режим не перепаковывает и не меняет приложение. Используйте его только с каталогом, полученным из своей проверенной сборки.
