# FlowDesk Desktop

Отдельное приложение на Electron для macOS, Windows и Linux. Оно открывает опубликованный FlowDesk в собственном окне и использует тот же Supabase через сайт. Переносить базу на компьютер не нужно. Работают уже опубликованные веб-функции; после обновления сайта они доступны и в клиенте.

## Возможности

- Собственное окно, иконка и меню.
- Отдельная сохраняемая сессия входа, независимо от обычного браузера.
- Восстановление размера и положения окна, обработка отключённого монитора.
- Переподключение `Ctrl+R` / `⌘R`, переход к отделам `Ctrl+Shift+H` / `⌘⇧H`, масштаб и полноэкранный режим.
- Страница отсутствия соединения и повторное подключение через меню «Файл».
- Внешние HTTPS-ссылки и подписанные ссылки на файлы открываются в системном браузере; загрузки внутри клиента спрашивают место сохранения. Скачанные файлы автоматически не запускаются.
- Блокировка второго экземпляра приложения.

Это сетевой клиент. Полной работы без интернета, собственной базы данных, автосинхронизации офлайн-правок и системных push-уведомлений нет. Вход внутри клиента — по логину/email и паролю FlowDesk. Вход через Google остаётся доступен в обычном браузере; его сессия не переносится в клиент автоматически.

## Запуск на вашем Mac

Установите Node.js 22 или новее. В распакованном проекте:

```bash
cd flowdesk/desktop
npm ci
npm start
```

Сайт и Supabase должны быть доступны через интернет. Docker и локальный Next.js для этого запуска не требуются. Адрес сайта задан в `desktop/app-config.json`:

```json
{"appUrl":"https://flowdesk-alpha-teal.vercel.app"}
```

Для другого собственного сайта измените `appUrl` перед сборкой. Допускается HTTPS-адрес без пути и параметров.

## Сборка приложения

На Mac:

```bash
cd desktop
npm ci
npm test
npm run dist:mac
```

Команду `cd desktop` выполняйте из корня проекта. Результаты — в `desktop/dist/` (`.dmg` и `.zip`). Для явного выбора процессора:

```bash
npx electron-builder --mac --arm64 --publish never
npx electron-builder --mac --x64 --publish never
```

Apple Silicon соответствует `arm64`, Intel — `x64`. Посмотреть свой процессор можно в меню Apple → «Об этом Mac».

На Windows используйте `npm run dist:win:x64` (или `dist:win:arm64` для ARM), на Linux — `npm run dist:linux`. Установщики собирайте в соответствующей ОС. GitHub Actions ниже выполняет эти сборки отдельно.

## Сборка через GitHub

В репозитории уже добавлен workflow **Desktop installers**:

1. Отправьте проект в GitHub.
2. Откройте Actions → Desktop installers → Run workflow → main.
3. Сначала выполнятся проверки веб-приложения, затем отдельные сборки для Mac Apple Silicon, Mac Intel, Windows x64/ARM64 и Linux x64.
4. Скачайте подходящий архив из раздела Artifacts завершённого запуска. Внутри будет установщик или архив приложения.

Workflow не публикует релизы автоматически. Подпись сертификатом разработчика и Apple notarization не настроены: подготовленные сборки предназначены для тестирования. Для распространения пользователям потребуется настроить подпись для соответствующей платформы. Сборки без подписи могут потребовать дополнительного подтверждения ОС при открытии; не отключайте защиту системы целиком.

## Разработка с локальным сервером

Запустите `npm run dev` из корня проекта в одном терминале. В другом:

```bash
cd desktop
FLOWDESK_DESKTOP_URL=http://localhost:3000 npm start
```

Переменная разрешена только в запуске из исходников, HTTP — только для localhost/loopback. Собранное приложение использует `app-config.json`.

## Границы доступа

Удалённая страница не получает Node.js, preload API или IPC. Включены context isolation, sandbox и web security. Новые окна внутри клиента запрещены, верхняя навигация остаётся на точном origin приложения, внешние ссылки допускают только HTTPS без логина и пароля. Разрешения устройства по умолчанию отклоняются. Ключи Supabase service role и токен Telegram в клиент не встраиваются.

Сессия хранится в профиле Electron на устройстве. Для выхода используйте обычное меню пользователя FlowDesk. Проверки доступа к отделам по-прежнему выполняет Supabase RLS.

## Проверка подготовленной поставки

Прошли 5 проверок URL/навигации и восстановления окна. Собран Linux AppImage. Реальный Electron запущен с тестовой страницей: проверены отсутствие `require` и `process` в renderer, запрет открытия `file:` и экран отсутствия соединения. Для headless-проверки в ограниченной среде только тестовый запуск отключал sandbox-флагом и подменял singleton-lock; в поставляемом `main.cjs` эти послабления отсутствуют. Полноценный запуск на macOS и Windows здесь не проверялся.

Отдельно подготовлены ZIP-архивы приложения для Mac Apple Silicon и Intel. Это неподписанные сборки из Linux с сохранением символьных ссылок macOS bundle. Распакуйте подходящий архив и перенесите `FlowDesk.app` в «Программы». Если macOS блокирует сборку, используйте собственную сборку на Mac по инструкции выше или настройте подпись разработчика. Глобально отключать защиту ОС не требуется.

Подробная инструкция Windows 11: [WINDOWS11.md](WINDOWS11.md).
